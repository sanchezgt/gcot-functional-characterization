enunciado: An adult man weighs 90 kg and is 1.80 m tall. Which of the following best describes his weight category by body mass index? Options: A. Normal weight B. Overweight C. Obesity class I D. Obesity class III
---
## PROGRESSION:ADVANCES
Need the BMI category for 90 kg and 1.80 m.

## SUPPORT
Adult BMI categories: below 18.5 underweight; 18.5–24.9 normal; 25–29.9 overweight; 30–34.9 obesity class I; 35–39.9 class II; 40 or more class III.

## ERROR
BMI: 90 / 1.80 = 50. Category: obesity class III.

## CORRECTION:RECOVERED | implicita
BMI divides by the height squared: 90 / (1.80 x 1.80) = 90 / 3.24 = 27.8, in the overweight range.

## PROGRESSION:REACHES_OUTPUT
Overweight. Answer: B.
