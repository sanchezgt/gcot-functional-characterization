## PROGRESSION:ADVANCES
We are given the equation 2x + 7 = 3x - 5 and need to solve for x.

## ALTERNATIVE:REJECTED | explicita
Alternatively, I could guess candidate values of x and test each one in the equation until both sides agree. But there is no hint about the range of x, so that could take many trials, and isolating x algebraically takes two steps. So I will not use trial and error.

## PROGRESSION:ADVANCES
Subtract 2x from both sides: 7 = x - 5.

## PROGRESSION:ADVANCES
Add 5 to both sides: 12 = x.

## SUPPORT
Each step applies the same operation to both sides of the equation, so the solution set is unchanged.

## PROGRESSION:REACHES_OUTPUT
Thus final answer: x = 12.
