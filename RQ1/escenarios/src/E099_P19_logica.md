## PROGRESSION:ADVANCES
Okay, let's see. Premises: all cats are mammals; some mammals are black. Conclusion: some cats are black. Is the argument valid?

## ALTERNATIVE:REJECTED | implicita
One quick route judges the argument by its conclusion: black cats exist, so the conclusion is true and the argument would come out valid. Validity, though, concerns whether the conclusion must follow from the premises, whatever the facts, so that route does not decide it.

## PROGRESSION:ADVANCES
The premises put all cats inside the set of mammals and say that some mammals are black. The black mammals could all be outside the cats, for example black dogs, so the premises don't force any cat to be black. The argument is invalid.

## VERIFICATION:CONFIRMED | implicita
The same form with other terms, all squares are shapes and some shapes are round, would license the conclusion that some squares are round, which is false while both premises are true, so the form does fail, as found.

## PROGRESSION:REACHES_OUTPUT
So the answer should be invalid.
