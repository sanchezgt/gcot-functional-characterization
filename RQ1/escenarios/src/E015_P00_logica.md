enunciado: Consider the following statements. (1) If it rained on Saturday, then the football match was postponed. (2) The football match was not postponed. Based only on these statements, did it rain on Saturday?

## PROGRESSION:ADVANCES
Okay, let's see. Two statements: if it rained, the match was postponed; and the match was not postponed. The question is whether it rained.

## PROGRESSION:ADVANCES
The first statement is a conditional: rain implies postponement. The second statement denies the consequent: no postponement.

## PROGRESSION:ADVANCES
When the consequent of a conditional is false, the antecedent must be false too, because if the antecedent were true the consequent would have to be true. This is the rule of modus tollens.

## SUPPORT
Modus tollens depends only on the form of the argument, not on what the statements are about, so it applies to rain and football matches as to any other conditional.

## PROGRESSION:REACHES_OUTPUT
So the answer should be no, it did not rain on Saturday.
